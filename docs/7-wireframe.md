## 4. 프로모션 상세 (PromotionDetail)

**액터**: User

**레이아웃 - 모바일** (DIRECT / ROULETTE 공통 골격, 하단 버튼만 타입별 분기)

```
┌─────────────────────────┐
│ ← 뒤로                   │
├─────────────────────────┤
│ [DIRECT] 여름 특가전      │
│ 기간: 08/01 ~ 08/31      │
│                          │
│ 상세설명(혜택/참여조건/   │
│ 참여방식/유의사항)        │
│ ...........              │
│ ...........              │
│                          │
├─────────────────────────┤
│ [DIRECT인 경우]           │
│   [      응모하기       ] │
│                          │
│ [ROULETTE인 경우]         │
│   남은 시도: 2/3회         │
│   [    룰렛 실행하기    ] │
└─────────────────────────┘
```

**레이아웃 - 데스크탑** (본문·액션 영역 2단 배치)

```
┌───────────────────────────────────────────────────┐
│ ← 뒤로                                              │
├───────────────────────────────────┬───────────────┤
│ [DIRECT] 여름 특가전                │ [DIRECT인 경우]│
│ 기간: 08/01 ~ 08/31                │  [ 응모하기 ] │
│                                     │               │
│ 상세설명(혜택/참여조건/             │ [ROULETTE인 경우]│
│  참여방식/유의사항)                 │ 남은 시도:2/3회│
│ .......................            │ [룰렛 실행하기]│
│ .......................            │               │
└───────────────────────────────────┴───────────────┘
```

**핵심 데이터 필드**: `Promotion.title`, `type`, `description`, `startAt`, `endAt`, `status`, (ROULETTE) `maxParticipationCount` 및 로그인 사용자의 `Participation.attemptCount`

**인터랙션**:
- [응모하기](DIRECT) → 참여 생성 성공 시 결과(PENDING) 표시. 중복 응모 시 오류 안내
- [룰렛 실행하기](ROULETTE) → §5 룰렛 결과 화면/영역으로 이동, 소진 시 버튼 비활성화
- 비로그인 상태에서 버튼 클릭 → 로그인 화면으로 유도

## 5. 룰렛 실행 결과 (RouletteResult)

**액터**: User

**레이아웃 - 모바일** (프로모션 상세 화면 내 결과 오버레이)

```
┌─────────────────────────┐
│ [ROULETTE] 룰렛이벤트     │
├─────────────────────────┤
│                          │
│       ┌───────────┐      │
│       │  🎯 결과   │      │
│       │  WIN / LOSE│      │
│       └───────────┘      │
│                          │
│  이번 시도(2회차) 결과입니다│
│  남은 시도: 1/3회          │
│                          │
│  [  다시 돌리기(잔여시)  ] │
│  [   참여내역으로 보기   ] │
└─────────────────────────┘
```

**레이아웃 - 데스크탑** (§4 데스크탑 레이아웃의 액션 영역 자리에 결과 오버레이)

```
┌───────────────────────────────────┬───────────────┐
│ [ROULETTE] 룰렛이벤트               │   🎯 결과      │
│ 기간: 08/10 ~ 08/20                │  WIN / LOSE   │
│                                     │ 2회차 결과입니다│
│ 상세설명...                        │ 남은 시도:1/3회│
│                                     │[다시 돌리기]   │
│                                     │[참여내역보기] │
└───────────────────────────────────┴───────────────┘
```

**핵심 데이터 필드**: `ParticipationAttempt.attemptNo`, `ParticipationAttempt.result`(WIN/LOSE), `Participation.attemptCount` / `Promotion.maxParticipationCount`

**인터랙션**: [다시 돌리기] → maxParticipationCount 미도달 시 재실행(§4로 복귀), 도달 시 버튼 비노출 / [참여내역으로 보기] → 내 참여내역 화면 이동

```
│ │ [수정][현황]          │ │
│ └─────────────────────┘ │
└─────────────────────────┘
```

**핵심 데이터 필드**: `Promotion.title`, `type`, `startAt`/`endAt`, `status`(UPCOMING/ONGOING/ENDED)

**인터랙션**: [+ 신규 등록] → §9 등록 폼 이동 / [수정] → §9 수정 폼(기존 값 채움) / [조기종료] → ONGOING 프로모션만 노출, 클릭 시 `status`를 즉시 ENDED로 전환(기존 Participation·ParticipationAttempt 보존) / [현황] → §11 참여 현황 이동
