## 1. 컬러 팔레트

| 토큰 | 값(근사치) | 용도 |
|------|-----------|------|
| `--color-primary` | `#3A9D5D` (그린) | 로고 포인트, 활성 탭 밑줄/텍스트, 라디오 선택, 강조 버튼(조회) |
| `--color-primary-dark` | `#2E7D4C` | 버튼 hover/active |
| `--color-header-dark` | `#1F2A24` (짙은 그린 블랙) | GNB 우측 "BO전환" 버튼, 탭 바(공지사항 활성 탭) 배경 |
| `--color-text-primary` | `#222222` | 본문/제목 텍스트 |
| `--color-text-secondary` | `#767676` | 비활성 메뉴, 보조 라벨(등록기간, 검색어 등) |
| `--color-border` | `#E0E0E0` | 테이블/카드/입력창 구분선 |
| `--color-bg-subtle` | `#F5F6F7` | 검색창/필터 영역 배경, 좌측 사이드바 배경 |
| `--color-badge-important` | `#E8536E` (레드/핑크) | "중요" 배지 |
| `--color-badge-important-bg` | `#FDE8EC` | "중요" 배지 배경 |
| `--color-white` | `#FFFFFF` | 카드/테이블/컨텐츠 배경 |

> 정확한 브랜드 색상 코드는 디자인 자산이 확보되면 교체. 위 값은 캡쳐 화면에서 육안으로 근사한 값이다.

## 2. 타이포그래피

- 폰트: 시스템 기본 산세리프(Pretendard, Noto Sans KR 등 한글 웹폰트 우선 적용 권장)
- 페이지 타이틀(예: "공지사항", "전체 이벤트"): **20px, bold**
- GNB 1depth 메뉴(기본설정/주문/재고 등): 16px, regular / 활성 메뉴는 초록색 + 하단 밑줄
- 사이드바(LNB) 메뉴: 15px, 비활성 `--color-text-secondary` / 활성 항목은 `--color-primary` + bold
- 테이블 헤더: 14px, medium, 정렬 화살표 아이콘 동반
- 테이블 본문/카드 텍스트: 14px, regular
- 보조 텍스트(등록일시, 조회수, 날짜 범위): 13px, `--color-text-secondary`

## 3. 레이아웃 구조

```
┌─────────────────────────────────────────────────────────┐
│ GNB: 로고 | 검색창(중앙) | 사업장선택 BO전환 아이콘들(우측) │  ← 상단 고정
├─────────────────────────────────────────────────────────┤
│ 1depth 메뉴: 기본설정 주문 재고 실적 결제 ... 커뮤니티     │  ← 활성 항목 초록 밑줄
├─────────────────────────────────────────────────────────┤
│ 탭 바(다크): 홈아이콘 | 열린 탭들(닫기 가능) | 화살표/메뉴  │
├───────────┬─────────────────────────────────────────────┤
│  LNB       │  컨텐츠 영역                                 │
│ (좌측고정) │  - 페이지 타이틀                              │
│  메뉴/     │  - 필터 바(검색조건 + 초기화/조회 버튼)        │
│  즐겨찾기   │  - 적용된 필터 칩 + 총 건수                   │
│  탭        │  - 테이블 또는 카드 그리드                     │
└───────────┴─────────────────────────────────────────────┘
```

- GNB, 1depth 메뉴, 탭 바는 스크롤 시에도 고정(sticky)
- LNB는 컨텐츠 영역과 별도 스크롤, 폭 고정(약 230px)
- 컨텐츠 영역 최대 폭은 두지 않고 LNB를 제외한 나머지 폭을 모두 사용

## 4. 컴포넌트

### 4.1 버튼

| 종류 | 스타일 |
|------|--------|
| Primary (조회) | `--color-primary` 배경, 흰 텍스트, radius 4px |
| Secondary (초기화) | `--color-header-dark` 배경, 흰 텍스트, radius 4px |
| 텍스트 버튼(탭 닫기 등) | 배경 없음, 아이콘만 |

버튼 높이는 입력창/셀렉트박스와 동일 선상 정렬(약 36px).

### 4.2 필터 바

- 라벨 + 인풋/라디오 그룹을 가로로 나열, 우측 끝에 초기화/조회 버튼 고정
- 라디오 버튼: 선택 시 `--color-primary` 채움, 라벨 텍스트는 항상 검정
- 날짜 범위: `시작일 ~ 종료일` 형태, 우측에 달력 아이콘
- 필터 적용 후에는 바로 아래에 적용된 조건을 칩(`구분 › 전체 ×`)으로 재노출

### 4.3 배지(Badge)

- "중요"처럼 우선순위/상태를 나타내는 텍스트는 알약형(pill) 배지로 표시
- 배경 `--color-badge-important-bg`, 텍스트 `--color-badge-important`, radius 999px(완전 둥근 형태), padding 2px 8px

### 4.4 테이블

- 헤더: `--color-bg-subtle` 배경, 컬럼별 정렬 토글 아이콘
- 행 구분: 배경색 없이 얇은 `--color-border` 하단 보더만 사용(zebra 스트라이프 없음)
- 첨부파일 컬럼: 클립 아이콘만 표시, 텍스트 없음
- 제목 컬럼은 좌측 정렬, 나머지(번호/구분/첨부/등록일시/조회)는 중앙 정렬

### 4.5 카드(이벤트 목록형)

- 그리드: 데스크탑 기준 정해진 컬럼 수(캡쳐는 2열이나 카드 폭 대비 가변 가능), 카드 간 gap 넉넉히
- 썸네일 이미지 상단(고정 비율), 하단에 제목(14~15px, medium) + 기간(13px, `--color-text-secondary`)
- 카드 자체에는 테두리/그림자 없음 — 이미지와 텍스트만으로 구성, 리스트 하단 구분선으로 섹션 마감

### 4.6 탭(작업 탭 바)

- 여러 화면을 탭으로 열어두는 다크 톤 탭 바(`--color-header-dark` 배경)
- 활성 탭은 흰 텍스트 + 살짝 밝은 배경, 비활성 탭은 회색 텍스트
- 각 탭에 닫기(×) 아이콘 포함, 탭 바 우측에 이전/다음 이동 및 전체 메뉴(⋮) 아이콘

---

## 5. 아이콘

- 라인 아이콘 사용(채움형 아님), 스트로크 두께 균일
- 상단 GNB 우측: 알림(종), 장바구니, 문서(클립보드), 사용자, 화면공유(cast), 로그아웃 순서로 배치
- 사이드바 각 메뉴 우측에 북마크(즐겨찾기 추가) 아이콘 배치

---

## 6. 반응형 원칙

`docs/7-wireframe.md`의 모바일/데스크탑 반응형 원칙을 그대로 따른다.

- 데스크탑(캡쳐 기준): GNB + 1depth 메뉴 + LNB 3단 구조 유지
- 모바일: LNB는 드로어(햄버거 메뉴)로 전환, 1depth 메뉴는 하단 탭바 또는 드롭다운으로 축소, 필터 바는 세로 스택, 테이블은 카드형 리스트로 전환 권장
- 카드 그리드는 모바일에서 1열로 축소
