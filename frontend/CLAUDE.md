# cjfreshway 프론트엔드 개발을 위한 지침

## 기술 스택 - 반드시 준수할 것 (docs/2-PRD.md §6)

- React 19를 사용할 것
- 전역 상태(인증 상태 등)는 Zustand로 관리할 것
- 서버 상태(프로모션/참여내역 등 API 데이터의 캐싱·재요청)는 TanStack Query로 관리할 것 — 캐싱/재요청 로직을 직접 구현하지 말 것
- 위 스택 외 별도 BFF, 상태관리 추가 라이브러리를 도입하지 말 것(오버엔지니어링 금지)
